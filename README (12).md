# Lab Sheets 1–10 — GitHub-ready files

Each lab is in its own folder. Open the folder in VS Code and upload the complete `LabSheets_1_to_10` folder to your GitHub repository.

**Important:** The PDF supplied in chat is a GitHub pull-request printout. Many files show only their filenames and their code areas are blank, so the contents below are clean, runnable starter implementations rather than a byte-for-byte recovery of every file from that pull request. Check your teacher's exact task instructions before submission.

## Run
- HTML/CSS/JavaScript labs: open the folder's `index.html` in a browser.
- Node.js labs: open a terminal in that lab folder, run `npm install` (if package.json exists), then `npm start`.
- Python/Django labs: follow that lab's README.
